# Rhythm Drive — My First Coding Project

A mobile-friendly rhythm game I built while learning web development.

**Play the game:** https://mahiisded-dev.github.io/rhythm-drive-game/

## How to play

- On a keyboard, use **A** and **D** to switch lanes and **Enter** to hit a tile.
- On a phone or tablet, tap the tiles as they reach the glowing line.

## What I learned

- **HTML** puts the game elements on the page.
- **CSS** styles the game and adapts it to smaller screens.
- **JavaScript** handles controls, tile timing, score, and Spotify connection.
- **GitHub Pages** publishes the site on the web.

## Spotify

Spotify connection requires a Spotify Developer app and a supported browser. Full playback requires Spotify Premium. Automatic BPM lookup may not be available to this app, so the game also has a manual BPM setting.

Never put a Spotify Client Secret in this public repository.
